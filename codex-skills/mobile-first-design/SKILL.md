# Goal
Design interfaces from the constraints of small screens first so the experience stays focused, usable, and performant on mobile devices.

# Instructions
1. Identify the most important tasks users must complete on mobile and trim non-essential UI first.
2. Design the smallest functional layout before expanding into larger breakpoint variations.
3. Prioritize touch ergonomics, reading comfort, navigation simplicity, and content hierarchy.
4. Scale up by adding space and richer layouts only when the screen can support them cleanly.
5. Test for one-handed use, slow networks, and interrupted user attention.

# Input
A request to create mobile-first layouts, improve mobile usability, design touch-friendly flows, or prioritize handheld device experiences.

# Output
Mobile-first page or component implementations, breakpoint logic, and interaction patterns optimized for touch and constrained screens.

# Best Practices
- Keep primary actions easy to reach and interact with on touch devices.
- Design for variable viewport heights, virtual keyboards, and orientation changes.
- Avoid desktop assumptions that create cramped or fragile mobile experiences.
- Keep payloads lean and progressive for better real-world mobile performance.
