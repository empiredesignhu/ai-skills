# Goal
Shape interfaces so users understand the value proposition, trust the product, and complete the intended action with minimal friction.

# Instructions
1. Determine the target conversion event and the major sources of hesitation or drop-off.
2. Audit information hierarchy, trust signals, form friction, CTA clarity, and distracting elements.
3. Redesign the flow so copy, layout, and interaction work together toward the same goal.
4. Make the value exchange explicit at every critical decision point.
5. Leave the interface easier to scan, easier to trust, and easier to complete.

# Input
A request to improve conversions on a page or interface, optimize a signup path, reduce friction, or strengthen CTA performance.

# Output
Conversion-oriented layout updates, interface refinements, supporting copy structure, and implementation changes that reduce user friction.

# Best Practices
- Align every major section and CTA with a single conversion objective.
- Reduce unnecessary fields, decisions, and visual competition.
- Reinforce trust with social proof, transparency, and clear expectations.
- Measure success through user behavior, not only visual polish.
