# Goal
Apply strong contemporary layout patterns that make interfaces feel intentional, current, and visually organized.

# Instructions
1. Understand the product context and determine which layout families fit the content and interaction model.
2. Choose a primary composition strategy such as split-screen, editorial grid, bento grouping, layered cards, or asymmetric hero structure.
3. Build layout rhythm through spacing, scale, alignment, and contrast rather than decoration alone.
4. Use pattern repetition to create cohesion while allowing key moments to break the grid deliberately.
5. Check that the final composition still supports usability, scanning, and responsiveness.

# Input
A request to modernize a UI layout, explore better composition patterns, improve page structure, or move away from stale boilerplate layouts.

# Output
Updated layouts, frontend structure, and visual composition choices that feel more current and purposeful.

# Best Practices
- Use hierarchy and whitespace strategically instead of filling every area.
- Let layout patterns support content importance, not merely visual novelty.
- Reuse clear structural primitives so the interface remains maintainable.
- Pair modern composition with accessible, responsive implementation.
