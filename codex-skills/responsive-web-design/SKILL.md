# Goal
Build interfaces that adapt gracefully across phones, tablets, laptops, and large screens without losing usability or visual coherence.

# Instructions
1. Identify the primary content priorities and interaction patterns across device sizes.
2. Start from the smallest viable layout and scale upward with intentional breakpoint changes.
3. Adjust layout, typography, spacing, and interaction density together instead of only resizing containers.
4. Handle overflow, wrapping, image behavior, and navigation changes explicitly at each breakpoint.
5. Verify edge cases such as long text, empty states, and form usability on narrow screens.

# Input
A request to make a page responsive, create adaptive breakpoints, rework mobile and desktop layouts, or fix clipped and crowded interfaces.

# Output
Responsive components or pages, updated breakpoint logic, and styling adjustments that improve behavior across screen sizes.

# Best Practices
- Favor fluid sizing, intrinsic layout, and content-driven breakpoints over device-specific hacks.
- Keep tap targets, readable line lengths, and interaction spacing appropriate for touch devices.
- Avoid hiding important functionality on smaller screens without a clear replacement.
- Test both compressed and expanded states so the design feels intentional at every size.
