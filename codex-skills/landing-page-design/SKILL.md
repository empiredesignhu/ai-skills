# Goal
Design and build landing pages that communicate value quickly, create momentum, and guide users toward a primary conversion action.

# Instructions
1. Clarify the audience, offer, traffic intent, and single primary action the page should drive.
2. Choose a strong visual direction and information hierarchy before arranging sections.
3. Build the page around a persuasive narrative: headline, proof, benefits, objections, and CTA flow.
4. Make supporting sections reinforce the conversion goal instead of adding generic filler.
5. Refine mobile behavior, CTA clarity, and scanning speed after the first pass.

# Input
A request to design or build a landing page, campaign page, waitlist page, launch page, or any standalone conversion-focused marketing surface.

# Output
Landing page layouts, frontend code, section structure, and messaging-aware UI that supports the page's conversion goal.

# Best Practices
- Keep one dominant CTA and reduce competing exits when possible.
- Support claims with proof such as testimonials, metrics, examples, or product visuals.
- Use strong hierarchy, spacing, and typography to improve scanability.
- Optimize for fast load, responsive behavior, and clear above-the-fold value communication.
